# Планировщик документов

Личный трекер сроков и задач: воинский учёт и военкомат, меддокументы, паспорт Беларуси,
водительские права, регистрация в Минске, Карта поляка и польская виза типа D.

Одна автономная HTML-страница: без сервера и зависимостей, данные — в localStorage браузера.
Экспорт/импорт JSON для резервных копий, печать плана, авторасчёт сроков от ключевых дат.

Страница: https://art19323.github.io/document-planner/

Не является юридической консультацией: требования перепроверяйте в военкомате, ОГиМ, ГАИ и консульстве.
